iGhostVT 1.6.1 smooths the phone's keyboard, brings back tab reordering on iOS 27, shortens Settings, and takes its accent colour from the terminal theme.

- On iPhone, raising or lowering the keyboard made the bottom bar ride up on the keys and the terminal jump twice, and closing the last tab with the keyboard up did the same. The bar now stays where it is and the keyboard covers it, and the terminal follows the keyboard in one movement.
- On iOS 27, holding a tab in the iPad sidebar opened its menu but the tab would not move. It drags to a new place again, and the tab overview's cards can now be dragged into a new order too, on iPhone as well.
- A file dropped on a terminal had to be dropped again to paste its path a second time. The tab's menu now lists the files dropped on it under Dropped Files; choosing one pastes its path again.
- In the accessory key editor, typing two hyphens turned them into a dash, so a key that sends `--option` sent something else. The fields now keep every character as typed, in a fixed-width font. An image dropped on the editor was ignored; it now offers Fill with Image. A `+` at the top of Accessory Keys adds a key without scrolling to the bottom.
- The accent colour no longer has a picker of its own: controls take the blue of the terminal theme, so the interface matches the terminal.
- Settings on iPhone and iPad took a long scroll to get through. Text size, New Session at Launch, Keep Sessions Running and Remember Directories are now one Terminal section, and the default shell has moved to Advanced. The interface text follows the system's text size; the Mac keeps its Interface scale.
- The New Tab menu's recent directories asked you to choose a sort order. They are now listed by how often you visit them, with older visits counting for less over time, so a directory you used this week comes before one you used last month. On the Mac the setting is now called Frequent Directories.

Choose `iphoneos-arm64e` for roothide, `iphoneos-arm64` for a rootless bootstrap, `iGhostVT-1.6.1-macos-notarized.zip` for a Mac — it is signed and notarized, so it opens without clearing quarantine, and updates itself — or `GhostRemote-1.6.1.ipa` for an iPhone or iPad without custom firmware, which your sideloading app signs as it installs it. To run the relay, use the attached `compose.yml`; the image is `ghcr.io/owngoal-dev/ighostvt-relay`, and the digest is in `relay-image.txt`. SHA-256 sums are in `SHA256SUMS`, and the Mac app's in `SHA256SUMS.macos`.
