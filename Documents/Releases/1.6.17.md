iGhostVT 1.6.17 keeps paired devices listed while Remote Access is off, makes ⌘T on a remote tab open where that tab is, and fixes Copy as One Line at word breaks.

- Turning Remote Access off hid the Authorized Devices list, as though the devices had been forgotten. They were only kept from connecting. The list now stays while the switch is off, and a device can still be removed there. Pair New Device returns when Remote Access is back on.
- ⌘T on a tab running on another device opened a terminal on that device in its home directory. It now opens in the directory the tab is in. ⌘T puts the new tab right after the current one. ⌘N and every other way of opening a tab put it at the end, and ⌘N always starts in this device's home directory.
- Copy as One Line glued words together where a program such as Claude Code had wrapped a line between them, because the space at the break is never drawn. Rows that break between words are now joined with a space. A path or link cut at the edge of the terminal still closes up, CJK text still joins without spaces, and a trailing `\` line continuation is dropped.
- The line beside a tab's title showed the program's name, which for Claude Code is only a version number such as `2.1.304`. It now shows the last part of the tab's directory, plus the device's name for a remote tab. The Live Activity lists each session the same way: its title, then the last part of its directory.
- The recent directories in the new-tab menu show only the folder name, without the full path under it.
- Settings now says that Background Activities keeps your sessions running after you quit the app.
