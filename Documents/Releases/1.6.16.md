iGhostVT 1.6.16 fixes modified Enter keys, so Shift+Enter inserts a newline in Claude Code on the Mac.

- On the Mac, Shift+Enter submitted a Claude Code prompt instead of inserting a newline, and Option+Enter and Control+Enter also reached terminal programs as a plain Enter. The terminal library now preserves these modifiers and lets the program's keyboard protocol encode them. Plain Enter still submits, and an input method keeps Return while composing text.

Choose `iphoneos-arm64e` for roothide, `iphoneos-arm64` for a rootless bootstrap, `iGhostVT-1.6.16-macos-notarized.zip` for a Mac — it is signed and notarized, so it opens without clearing quarantine, and updates itself — or `GhostRemote-1.6.16.ipa` for an iPhone or iPad without custom firmware, which your sideloading app signs as it installs it. To run the relay, use the attached `compose.yml`; the image is `ghcr.io/owngoal-dev/ighostvt-relay`, and the digest is in `relay-image.txt`. SHA-256 sums are in `SHA256SUMS`, and the Mac app's in `SHA256SUMS.macos`.
